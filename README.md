# StickerDesk

Always-on-top stickers for Windows, with text, images, saved history, light and dark themes, and individual virtual-desktop settings.

**[Download StickerDesk for Windows](https://github.com/eroldev/stickerdesk-releases/releases/latest/download/eroldev.StickerDesk-win-Setup.exe)**

Windows 10/11, x64. The installer includes everything needed to run the app. This is an early-access build; a private StickerDesk license file is required to activate it. Licenses are currently issued privately and are not sold from this page.

1. Run the installer.
2. Choose your private `.stickerlicense` file on first launch.
3. Use the tray icon to create stickers or open **Updates…**. Choose **Download & restart** when a new version is available.

Stickers, images and history stay on each PC. There is no cloud sync. Activation works offline, and updates preserve your local data and license. Keep your license file private.

The installer is currently unsigned; Windows may show an unknown-publisher warning.

This repository hosts downloads only. StickerDesk source code is private. Third-party software notices are included in the installation.
